# ZUMO-GO
A platformer thinky game created for ThinkyConJam 2025 by Marcos Constantino and Romina Garcia. 
Inspired by all the amazing talks of ThinkyCon 2025, especially the one by Daria Jerjomin's: Designing Puzzles Based on Real Languages

## 🔎 About

In this game you explore an abandoned cave, and paying attention to the strange texts on the walls you'd need to solve linguistic puzzles to find the three lost gems.

## 💻 Play

You can download and play the game from the [itchio page](https://romi121.itch.io/zumo-go)
